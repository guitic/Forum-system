1: # 在线论坛系统 V3.0
2: 
3: 基于 HTML/JS + Python 的轻量级技术交流论坛，前后端分离架构，完全适配 Rocky Linux 生产环境部署。
4: 
5: - **V1.1**：注册登录 / 发帖 / 评论 / JWT 鉴权 / Markdown 渲染
6: - **V2.0**：用户中心（昵称、简介、头像、修改密码）
7: - **V3.0**：帖子详情 + 层级回复（楼中楼，最多 3 层）+ 楼主/Admin 徽标 + 回复级联删除
8: 
9: ## 技术栈
10: 
11: | 层次 | 技术选型 |
12: |------|----------|
13: | **前端** | 原生 HTML + CSS + JavaScript |
14: | **Markdown** | marked.js + highlight.js（15 种语言高亮） |
15: | **后端** | Python 3 + Flask + SQLAlchemy |
16: | **数据库** | MariaDB / MySQL |
17: | **认证** | Bcrypt 密码哈希 + JWT（HS256, 24h 过期） |
18: | **部署** | Nginx + systemd + Crontab 监控 |
19:

69: ## API 接口
70: 
71: | 方法 | 路径 | 鉴权 | 说明 |
72: |------|------|------|------|
73: | POST | `/api/auth/register` | ❌ | 用户注册 |
74: | POST | `/api/auth/login` | ❌ | 用户登录，返回 JWT |
75: | GET | `/api/posts` | ❌ | 帖子列表（分页） |
76: | GET | `/api/posts/{id}` | ❌ | 帖子详情 + 层级回复树（V3：reply_tree / reply_count） |
77: | POST | `/api/posts` | ✅ Bearer | 发布新帖 |
78: | POST | `/api/posts/{id}/replies` | ✅ Bearer | 发布回复（V3：Body 可选 `parent_id` 实现楼中楼） |
79: | DELETE | `/api/posts/{id}` | ✅ Bearer | 删除帖子（仅作者/管理员） |
80: | DELETE | `/api/replies/{reply_id}` | ✅ Bearer | 删除回复（V3：级联删除子孙，仅作者/管理员） |
81: | GET | `/api/user/profile` | ✅ Bearer | 获取个人资料（V2） |
82: | PUT | `/api/user/profile` | ✅ Bearer | 更新昵称与简介（V2） |
83: | POST | `/api/user/password` | ✅ Bearer | 修改密码（V2） |
84: | POST | `/api/user/avatar` | ✅ Bearer | 上传头像（V2） |
85: | GET | `/uploads/<filename>` | ❌ | 头像静态资源服务（V2） |
86: | GET | `/health` | ❌ | 健康检查 |

88: ## 快速启动
89: 
90: ### 1. 后端环境
91: 
92: ```bash
93: cd backend
94: python -m venv venv
95: source venv/bin/activate  # Linux/macOS
96: pip install -r requirements.txt
97: ```
98: 
99: ### 2. 配置数据库
100: 
101: 编辑 `backend/config.py` 或设置环境变量：
102: 
103: ```bash
104: export DB_HOST=localhost
105: export DB_PORT=3306
106: export DB_USER=forum_user
107: export DB_PASSWORD=[REDACTED:credential]
108: export DB_NAME=forum_db
109: export SECRET_KEY=your-secret-key-here
110: ```
111: 
112: ### 3. 初始化数据库
113: 
114: ```bash
115: # 方式一：执行 SQL 脚本
116: mysql -u root -p < database/init.sql
117: 
118: # 方式二：使用 Python 脚本（推荐）
119: cd backend
120: python init_db.py
121: 
122: # 自定义管理员账号
123: python init_db.py --admin admin --admin-pass MyStrongPass123
124: 
125: # V2 用户中心迁移（已存在的数据库执行）
126: mysql -u root -p < database/migration_v2.sql
127: 
128: # V3 回复层级迁移（已存在的数据库执行；本地 SQLite 跑 init_db.py 会自动补列）
129: mysql -u root -p < database/migration_v3.sql
130: 
131: # V3 层级回复端到端自测（42 项，使用独立测试库，不污染开发库）
132: cd backend && python tests/test_reply_hierarchy.py
133: ```
134: 
135: ### 4. 启动后端
136: 
137: ```bash
138: cd backend
139: python app.py
140: # 服务运行在 http://localhost:5000
141: ```

194: ## 安全特性
195: 
196: - Bcrypt 密码哈希（密码 ≥8 字符，截断 72 字节）
197: - JWT 鉴权（HS256，24h 过期，自动刷新）
198: - XSS 白名单清洗（阻止 javascript:/data: 协议）
199: - 用户名枚举防护（登录错误信息统一）
200: - 密码强度要求（字母+数字+特殊字符）
201: - 头像上传安全校验（MIME+扩展名+文件大小 2MB+UUID文件名）
202: - 目录遍历防护（上传文件路径校验）
203: - Nginx 安全头（HSTS/CSP/X-Frame-Options/XSS-Protection）
204: - systemd 沙箱加固（ProtectSystem=strict/NoNewPrivileges）
205: - 请求限速（Nginx limit_req）
206: - 回复层级校验（V3：`parent_id` 必须归属同一帖子，跨帖挂接返回 403）
207: - 回复删除权限（V3：仅作者或管理员，级联删除子树避免孤立引用）
