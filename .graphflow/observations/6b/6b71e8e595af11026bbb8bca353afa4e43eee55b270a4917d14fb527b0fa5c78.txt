100: ## 3. 数据库初始化
101: 
102: ### 3.1 安装并启动 MariaDB
103: 
104: ```bash
105: sudo dnf install -y mariadb mariadb-server
106: sudo systemctl enable --now mariadb
107: sudo mysql_secure_installation   # 交互式配置安全选项
108: ```
109: 
110: ### 3.2 创建数据库与用户
111: 
112: ```bash
113: sudo mariadb -u root <<'SQL'
114: CREATE DATABASE IF NOT EXISTS forum
115:     CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
116: 
117: CREATE USER IF NOT EXISTS 'forum'@'localhost' IDENTIFIED BY 'CHANGE_ME_STRONG_PASSWORD';
118: CREATE USER IF NOT EXISTS 'forum'@'127.0.0.1' IDENTIFIED BY 'CHANGE_ME_STRONG_PASSWORD';
119: 
120: GRANT ALL PRIVILEGES ON forum.* TO 'forum'@'localhost';
121: GRANT ALL PRIVILEGES ON forum.* TO 'forum'@'127.0.0.1';
122: 
123: FLUSH PRIVILEGES;
124: SQL
125: ```
126: 
127: ### 3.3 创建表结构 (参照需求文档)
128: 
129: ```bash
130: sudo mariadb -u forum -pCHANGE_ME_STRONG_PASSWORD forum <<'SQL'
131: CREATE TABLE IF NOT EXISTS users (
132:     id            INT AUTO_INCREMENT PRIMARY KEY,
133:     username      VARCHAR(50) NOT NULL UNIQUE,
134:     password_hash VARCHAR(255) NOT NULL,
135:     role          VARCHAR(20) NOT NULL DEFAULT 'user',
136:     created_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
137:     KEY idx_users_username (username)
138: ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
139: 
140: CREATE TABLE IF NOT EXISTS posts (
141:     id         INT AUTO_INCREMENT PRIMARY KEY,
142:     user_id    INT NOT NULL,
143:     title      VARCHAR(100) NOT NULL,
144:     content    TEXT NOT NULL,
145:     created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
146:     KEY idx_posts_user_id (user_id),
147:     KEY idx_posts_created_at (created_at),
148:     CONSTRAINT fk_posts_user FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
149: ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
150: 
151: CREATE TABLE IF NOT EXISTS replies (
152:     id         INT AUTO_INCREMENT PRIMARY KEY,
153:     post_id    INT NOT NULL,
154:     user_id    INT NOT NULL,
155:     content    TEXT NOT NULL,
156:     created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
157:     KEY idx_replies_post_id (post_id),
158:     KEY idx_replies_user_id (user_id),
159:     CONSTRAINT fk_replies_post FOREIGN KEY (post_id) REFERENCES posts(id) ON DELETE CASCADE,
160:     CONSTRAINT fk_replies_user FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
161: ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
162: SQL
163: ```

258: | `root` | `nginx.conf` | 替换为前端实际目录 |

359: ### 7.1 手动执行巡检
360:

362: # 完整巡检

365: # 仅打印，不发邮件

370: 
371: # 详细调试
372: python3 /opt/forum/scripts/monitor.py --verbose
373: ```
374: 
375: ### 7.2 配置 SMTP 告警
376: 
377: **方案 A: 阿里云 / 腾讯云 邮件推送**
378: 
379: 1. 创建发信地址并获取 SMTP 授权码
380: 2. 修改 `monitor.py` 中的 `CONFIG`:
381:    - `smtp_host`: `smtp.mxhichina.com` (阿里云) / `smtp.qiye.aliyun.com`
382:    - `smtp_port`: `465`
383:    - `smtp_use_ssl`: `True`
384:    - `smtp_user`: `forum-alert@example.com`
385:    - `smtp_password`: SMTP 授权码
386:    - `alert_to`: 接收告警的邮箱
387: 
388: **方案 B: 企业邮箱**
389: 
390: 1. 启用 SMTP 服务并获取密码
391: 2. `smtp_host`: 企业邮箱 SMTP 服务器 (如 `smtp.corp.example.com`)
392: 3. `smtp_port`: `465` (SSL) 或 `587` (STARTTLS)
393: 
394: **方案 C: 自建 Mailu / iRedMail**
395: 
396: 1. 部署内部邮件服务器
397: 2. `smtp_host`: `mail.example.com`
398: 3. `smtp_port`: `25` 或 `465`
399: 
400: ### 7.3 自定义告警阈值
401: 
402: 修改 `monitor.py` 中的 `CONFIG`:
403: 
404: ```python
405: CONFIG = {
406:     "error_5xx_threshold": 10,      # 5xx 阈值
407:     "error_log_threshold": 5,       # error.log 阈值
408:     "disk_threshold": 85,           # 磁盘阈值
409:     "memory_threshold": 90,         # 内存阈值
410:     "load_threshold": 2.0,          # CPU 负载比
411:     "consecutive_failures_threshold": 3,  # 连续失败抑制
412:     ...
413: }

625: ## 11. 安全加固建议
626: 
627: 1. **HTTPS 强制跳转**: 部署 Let's Encrypt 证书并启用 HSTS
628:    ```bash
629:    sudo dnf install -y certbot python3-certbot-nginx
630:    sudo certbot --nginx -d forum.example.com
631:    ```
632: 2. **最小权限原则**: 服务以 `forum` 用户运行，非 root
633: 3. **systemd 沙箱**: 启用 `ProtectSystem=strict`、`NoNewPrivileges` 等指令
634: 4. **定期更新系统包**:
635:    ```bash
636:    sudo dnf update -y
637:    ```
638: 5. **fail2ban**: 限制 SSH 与登录尝试
639:    ```bash
640:    sudo dnf install -y fail2ban
641:    sudo systemctl enable --now fail2ban
642:    ```
643: 6. **文件权限**: 敏感配置文件 `chmod 600`
644: 7. **网络隔离**: 仅开放 80/443，其余端口走防火墙
645: 8. **定期备份**: 数据库 + 配置 + 代码，保留至少 7 天
646: 9. **审计日志**: 开启 `auditd` 监控关键操作
647: 10. **配置分离**: 敏感信息使用 `EnvironmentFile`，不进入 Git 仓库
